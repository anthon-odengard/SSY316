# Assignments

This directory contains all course assignments for SSY316.

## Assignment List

Assignments will be added throughout the course. Each assignment will have its own subdirectory.

## Submission Guidelines

- Complete assignments individually unless group work is specified
- Submit your solutions through the course management system
- Include all code, documentation, and results
- Follow the naming convention: `assignment_X_yourname`

## Structure

Each assignment directory typically contains:
- Problem description (PDF or Markdown)
- Starter code (if applicable)
- Data files (if applicable)
- Submission template
