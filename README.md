# SSY316 - Advanced Probabilistic Machine Learning

Repository for course SSY316: Advanced Probabilistic Machine Learning at Chalmers University of Technology.

## Course Description

This course covers advanced topics in probabilistic machine learning, including:
- Probabilistic graphical models
- Bayesian inference and learning
- Variational inference
- Monte Carlo methods
- Deep probabilistic models
- Gaussian processes

## Repository Structure

```
SSY316/
├── assignments/     # Course assignments and homework
├── lectures/        # Lecture notes and materials
├── projects/        # Course projects
└── resources/       # Additional learning resources
```

## Getting Started

### Prerequisites
- Python 3.8 or higher
- Jupyter Notebook
- Basic knowledge of probability theory and machine learning

### Installation

1. Clone this repository:
```bash
git clone https://github.com/anthon-odengard/SSY316.git
cd SSY316
```

2. Install required packages:
```bash
pip install -r requirements.txt
```

## Course Materials

Course materials are organized by week in the `lectures/` directory. Assignments can be found in the `assignments/` directory.
