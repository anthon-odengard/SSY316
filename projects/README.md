# Projects

This directory contains course project materials for SSY316.

## Project Overview

The course project allows you to apply probabilistic machine learning techniques to real-world problems.

## Project Guidelines

- Projects can be completed individually or in groups (size TBD)
- Choose a topic related to probabilistic machine learning
- Project proposals should be submitted by the specified deadline
- Final project submissions include code, report, and presentation

## Project Structure

A typical project should include:
- Project proposal
- Literature review
- Implementation
- Experimental results
- Final report
- Presentation slides

## Evaluation Criteria

Projects will be evaluated based on:
- Technical soundness
- Innovation and creativity
- Quality of implementation
- Clarity of presentation
- Results and analysis
